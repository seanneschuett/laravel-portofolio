Saya ingin mengembangkan website portofolio Laravel yang sudah ada untuk memenuhi seluruh kriteria penilaian ujian KIK UKK. Website ini sudah selesai dibuat dan berhasil di-deploy menggunakan Railway serta terhubung dengan database MySQL Railway. Login admin juga sudah berfungsi.

TUGAS PERTAMA: LAKUKAN AUDIT PROJECT TERLEBIH DAHULU. JANGAN MENGUBAH ATAU MENAMBAHKAN KODE APAPUN.

ATURAN UTAMA:
1. Jangan mengubah layout, desain, struktur visual, warna, gradient, font, ukuran teks, spacing, padding, margin, border, shadow, maupun animasi yang sudah ada.
2. Jangan mengganti tema atau membuat desain ulang.
3. Jangan menghapus, mengganti, atau merusak fitur yang sudah berjalan.
4. Pertahankan teknologi, struktur folder, pola coding, dan arsitektur Laravel yang sudah digunakan.
5. Jangan melakukan deployment, git push, atau mengubah konfigurasi Railway.
6. Jangan mengarang informasi pribadi, pengalaman, sertifikat, testimoni, atau data proyek.

PERIKSA SELURUH BAGIAN BERIKUT:
- Struktur folder dan file Laravel.
- Versi Laravel dan dependensi yang digunakan.
- Route pada routes/web.php.
- Controller dan Model.
- Migration dan struktur tabel database.
- Seluruh halaman Blade dan komponen layout.
- Sistem autentikasi admin.
- Dashboard admin dan fitur CRUD yang sudah tersedia.
- Sistem upload gambar atau file.
- Halaman beranda dan halaman kontak.
- Fitur galeri proyek yang sudah ada.
- Hubungan antara frontend, backend, dan database.
- Responsive design.
- Integrasi dan konfigurasi deployment Railway.

BERIKUT KRITERIA PENILAIAN KIK UKK YANG HARUS DIPENUHI:
A. Beranda: foto profil, nama lengkap, kelas, kompetensi keahlian, deskripsi personal branding, keahlian utama, tombol lihat portofolio, lihat CV, hubungi saya.
B. About Me: biodata, pendidikan, minat teknologi, organisasi, PLK, tujuan karir.
C. Skills: hard skill dan soft skill menggunakan persentase.
D. My Project: nama, gambar, deskripsi, masalah, tujuan, teknologi, peran, fitur, link demo, GitHub, dokumentasi proses, detail proyek, feedback pengguna.
E. Sertifikat dan Prestasi: sertifikat, prestasi, dokumentasi.
F. Experience: PLK, organisasi, lomba.
G. CV Digital.
H. Kontak: email, GitHub, Instagram, LinkedIn.
I. Formulir kesan dan pesan.
J. Responsive design.
K. Fitur interaktif: dark/light mode, animasi pergantian halaman, navigasi mudah, tombol kembali ke atas, preview proyek.
L. Dashboard admin: login/logout, CRUD, upload foto proyek, tambah/hapus sertifikat, mengelola profil, mengelola pesan masuk, dan mengubah konten tanpa mengedit kode.
M. Testimoni: guru pembimbing, teman, pengguna, tempat PLK.
N. Blog pengembang/artikel/catatan coding.
O. Minimal satu fitur tambahan. Prioritaskan pencarian dan filter proyek.

FORMAT HASIL AUDIT:
1. Jelaskan teknologi dan struktur project yang ditemukan.
2. Buat tabel berisi setiap kriteria A sampai O dengan status: SUDAH ADA, BELUM ADA, atau PERLU DISEMPURNAKAN.
3. Sebutkan file yang berkaitan dengan setiap fitur.
4. Jelaskan fitur yang sudah berjalan dan jangan dibuat ulang.
5. Identifikasi tabel database yang sudah tersedia dan tabel yang mungkin perlu ditambahkan.
6. Berikan rekomendasi urutan implementasi berdasarkan kondisi project sebenarnya.
7. Identifikasi risiko perubahan kode yang bisa menyebabkan fitur lama rusak.

PENTING: Jangan melakukan perubahan kode terlebih dahulu. Setelah audit selesai, tampilkan laporan lengkap dan tunggu instruksi saya sebelum mulai mengimplementasikan fitur.
